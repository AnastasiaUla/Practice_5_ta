## 2. Краткие теоретические сведения

Контекстно-свободная грамматика задаётся четвёркой:

\[
G=(N,\Sigma,P,S),
\]

где `N` — множество нетерминалов, `Σ` — множество терминалов, `P` — множество правил вывода, `S` — начальный символ грамматики.

**FIRST** — множество терминалов, с которых могут начинаться цепочки, выводимые из заданного нетерминала.

**FOLLOW** — множество терминалов, которые могут непосредственно следовать за заданным нетерминалом. Символ `$` обозначает конец входной цепочки, `ε` — пустую цепочку.

**LL(1)** — метод нисходящего синтаксического анализа, который просматривает входную цепочку слева направо, строит левый вывод и использует один символ предпросмотра. Для грамматики LL(1) каждая клетка таблицы предсказывающего анализа должна содержать не более одной продукции.

**Метод рекурсивного спуска** — способ реализации нисходящего анализа, при котором каждому нетерминалу грамматики соответствует отдельная функция программы.

**SLR(1)** — метод восходящего синтаксического анализа, основанный на LR(0)-ситуациях и множествах FOLLOW. Таблица анализа содержит действия переноса, свёртки и принятия. Отсутствие конфликтов переноса/свёртки и свёртки/свёртки подтверждает принадлежность грамматики к классу SLR(1).

## 3. Часть 1. Построение LL(1)-грамматики

**Файл модели:** [`grammar_ll1.jff`](grammar_ll1.jff).

Аксиомой грамматики является `S`. Грамматика описывает один оператор присваивания, в котором слева располагается переменная `a`–`j`, а справа — выражение с двоичными константами и побитовыми операциями.

### 3.1. Правила грамматики

```text
S -> V=E

E -> TA
A -> ^TA
A -> |TA
A -> ε

T -> UM
M -> &UM
M -> ε

U -> ~U
U -> P

P -> (E)
P -> V
P -> B

V -> a | b | c | d | e | f | g | h | i | j

B -> 0Q
B -> 1Q

Q -> 0Q
Q -> 1Q
Q -> ε
```

В JFLAP каждая альтернатива вводится отдельной продукцией. Пустая правая часть используется для обозначения `ε`.

Назначение нетерминалов:

- `S` — начальный символ, задающий оператор присваивания;
- `V` — однобуквенная переменная;
- `E` — выражение;
- `A` — продолжение выражения на уровне операций `^` и `|`;
- `T` — терм;
- `M` — продолжение терма на уровне операции `&`;
- `U` — унарное выражение;
- `P` — простой операнд;
- `B` — двоичная константа;
- `Q` — продолжение последовательности двоичных цифр.

Грамматика учитывает приоритет операций: унарное отрицание имеет наивысший приоритет, затем выполняется побитовое И, а после него — побитовые операции исключающего ИЛИ и ИЛИ.

Левая рекурсия устранена. Продолжения выражений описаны с помощью нетерминалов `A` и `M`, что позволяет использовать грамматику для LL(1)-анализа.

### 3.2. Множества FIRST и FOLLOW

| Нетерминал | FIRST | FOLLOW |
|---|---|---|
| `S` | `a b c d e f g h i j` | `$` |
| `E` | `~ ( a b c d e f g h i j 0 1` | `$ )` |
| `A` | `^ \| ε` | `$ )` |
| `T` | `~ ( a b c d e f g h i j 0 1` | `^ \| $ )` |
| `M` | `& ε` | `^ \| $ )` |
| `U` | `~ ( a b c d e f g h i j 0 1` | `& ^ \| $ )` |
| `P` | `( a b c d e f g h i j 0 1` | `& ^ \| $ )` |
| `V` | `a b c d e f g h i j` | `= & ^ \| $ )` |
| `B` | `0 1` | `& ^ \| $ )` |
| `Q` | `0 1 ε` | `& ^ \| $ )` |

### 3.3. Таблица предсказывающего анализа LL(1)

Ниже приведено сжатое представление таблицы. Если для нетерминала и входного символа указана продукция, она выбирается при выполнении анализа. Все неуказанные клетки являются ошибочными.

| Нетерминал | Входной символ | Выбираемая продукция |
|---|---|---|
| `S` | `a`–`j` | `S → V=E` |
| `E` | `~`, `(`, `a`–`j`, `0`, `1` | `E → TA` |
| `A` | `^` | `A → ^TA` |
| `A` | `\|` | `A → \|TA` |
| `A` | `)`, `$` | `A → ε` |
| `T` | `~`, `(`, `a`–`j`, `0`, `1` | `T → UM` |
| `M` | `&` | `M → &UM` |
| `M` | `^`, `\|`, `)`, `$` | `M → ε` |
| `U` | `~` | `U → ~U` |
| `U` | `(`, `a`–`j`, `0`, `1` | `U → P` |
| `P` | `(` | `P → (E)` |
| `P` | `a`–`j` | `P → V` |
| `P` | `0`, `1` | `P → B` |
| `B` | `0` | `B → 0Q` |
| `B` | `1` | `B → 1Q` |
| `Q` | `0` | `Q → 0Q` |
| `Q` | `1` | `Q → 1Q` |
| `Q` | `&`, `^`, `\|`, `)`, `$` | `Q → ε` |

Для нетерминала `V` на каждый символ `a`–`j` выбирается соответствующая продукция, выводящая этот терминал.

### 3.4. Обоснование принадлежности грамматики к классу LL(1)

Для альтернатив нетерминалов `V`, `B`, `P` множества FIRST не пересекаются.

Для нетерминала `U` первая альтернатива начинается с `~`, а вторая — с символов множества FIRST(`P`). Пересечений нет.

Для нетерминала `A` непустые альтернативы начинаются с `^` и `|`. Эти символы не входят в FOLLOW(`A`), поэтому выбор между непустыми альтернативами и пустой продукцией однозначен.

Для нетерминала `M` непустая альтернатива начинается с `&`, который не входит в FOLLOW(`M`).

Таким образом, при выборе продукции используется один символ предпросмотра. В таблице предсказывающего анализа отсутствуют неоднозначные клетки, следовательно, построенная грамматика является **LL(1)**.

## 4. Часть 2. Реализация метода рекурсивного спуска

**Файл программы:** [`recursive_descent.py`](recursive_descent.py).

Для второй части реализован синтаксический анализатор методом рекурсивного спуска. Программа проверяет, соответствует ли введённая цепочка заданной грамматике. Результат проверки выводится в виде `Accepted` или `Rejected`.

### 4.1. Описание входных данных

В анализируемом языке используются следующие элементы:

| Элемент | Обозначение |
|---|---|
| Двоичные константы | `0b` и последовательность цифр `0`, `1` |
| Троичные константы | `0t` и последовательность цифр `0`, `1`, `2` |
| Десятичные константы | Последовательность цифр `0`–`9` |
| Идентификаторы | От одной до двух латинских букв |
| Унарная операция | `~` |
| Бинарные операции | `&`, `^`, `\|` |
| Присваивание | `=` |
| Скобки | `(` и `)` |
| Разделитель выражений | `;` или перевод строки |

Пробелы между элементами выражения игнорируются. Программа проверяет синтаксическую корректность записи, но не вычисляет значения выражений.

### 4.2. Грамматика анализатора

```text
E -> ID R
E -> N A X O

R -> =E
R -> A X O

N -> ~U
N -> (E)
N -> BIN
N -> TER
N -> DEC

U -> ~U
U -> (E)
U -> ID
U -> BIN
U -> TER
U -> DEC

A -> &UA
A -> ε

X -> ^CX
X -> ε

C -> UA

O -> |DO
O -> ε

D -> CX
```

Назначение нетерминалов:

- `E` — выражение;
- `R` — продолжение выражения с возможным присваиванием;
- `N` — унарное выражение или простой операнд;
- `U` — операнд;
- `A` — продолжение операции побитового И;
- `X` — продолжение операции исключающего ИЛИ;
- `C` — выражение уровня побитового И;
- `O` — продолжение операции побитового ИЛИ;
- `D` — выражение уровня исключающего ИЛИ.

### 4.3. Множества FIRST и FOLLOW

| Нетерминал | FIRST | FOLLOW |
|---|---|---|
| `E` | `ID ~ ( BIN TER DEC` | `) ; $` |
| `R` | `= & ^ \| ε` | `) ; $` |
| `N` | `~ ( BIN TER DEC` | `& ^ \| ) ; $` |
| `U` | `~ ( ID BIN TER DEC` | `& ^ \| ) ; $` |
| `A` | `& ε` | `^ \| ) ; $` |
| `X` | `^ ε` | `\| ) ; $` |
| `C` | `~ ( ID BIN TER DEC` | `^ \| ) ; $` |
| `O` | `\| ε` | `) ; $` |
| `D` | `~ ( ID BIN TER DEC` | `\| ) ; $` |

### 4.4. Доказательство принадлежности грамматики к классу LL(1)

Для нетерминала `E` альтернативы начинаются с разных терминалов: `ID` и символов, входящих в FIRST(`N`). Пересечений нет.

Для `R` первая альтернатива начинается с `=`, а вторая может начинаться с `&`, `^`, `|` либо выводить пустую цепочку. Символы FOLLOW(`R`) не пересекаются с FIRST непустых альтернатив.

Для `A` непустая альтернатива начинается с `&`, который не входит в FOLLOW(`A`).

Для `X` непустая альтернатива начинается с `^`, который не входит в FOLLOW(`X`).

Для `O` непустая альтернатива начинается с `|`, который не входит в FOLLOW(`O`).

Остальные нетерминалы имеют альтернативы с непересекающимися множествами FIRST.

Следовательно, для каждой пары «нетерминал — следующий входной символ» можно однозначно определить продукцию. Грамматика относится к классу **LL(1)**.

### 4.5. Принцип работы программы

Программа состоит из нескольких основных этапов:

1. **Лексический анализ.** Входная строка разбивается на токены: идентификаторы, числовые константы, операции и скобки.
2. **Проверка токенов.** Определяется корректность записи чисел в соответствующих системах счисления и допустимая длина идентификаторов.
3. **Синтаксический анализ.** Методы рекурсивного спуска последовательно проверяют структуру выражения.
4. **Проверка завершения.** После разбора программа проверяет, что все входные токены обработаны.
5. **Вывод результата.** При отсутствии ошибок выводится `Accepted`, иначе — `Rejected`.

Для реализации используются методы разбора выражений, унарных операций, операндов и продолжений выражений. При обнаружении несоответствия грамматике возникает ошибка разбора, после чего программа возвращает `Rejected`.

## 5. Часть 3. Построение SLR(1)-грамматики

**Файл модели:** [`grammar_slr1.jff`](grammar_slr1.jff).

В третьей части построена отдельная грамматика для последовательностей операторов присваивания. В отличие от первой части, здесь используются двоичные и восьмеричные константы. Переменные представлены одной латинской буквой от `a` до `j`.

Операторы присваивания разделяются символом `;`. В правой части допускаются унарное отрицание, бинарные операции и скобки.

### 5.1. Правила грамматики

```text
S' -> S

S -> S;A
S -> A

A -> V=E

V -> a
V -> b
V -> c
V -> d
V -> e
V -> f
V -> g
V -> h
V -> i
V -> j

E -> E|T
E -> T

T -> T^F
T -> F

F -> F&G
F -> G

G -> ~G
G -> (E)
G -> V
G -> B
G -> O

B -> 0bD

D -> D0
D -> D1
D -> 0
D -> 1

O -> 0oH

H -> H0
H -> H1
H -> H2
H -> H3
H -> H4
H -> H5
H -> H6
H -> H7
H -> 0
H -> 1
H -> 2
H -> 3
H -> 4
H -> 5
H -> 6
H -> 7
```

Назначение нетерминалов:

- `S'` — дополненный начальный символ;
- `S` — последовательность операторов присваивания;
- `A` — отдельный оператор присваивания;
- `V` — переменная;
- `E` — выражение с операцией побитового ИЛИ;
- `T` — выражение с операцией исключающего ИЛИ;
- `F` — выражение с операцией побитового И;
- `G` — простой операнд или унарное выражение;
- `B` — двоичная константа;
- `D` — последовательность двоичных цифр;
- `O` — восьмеричная константа;
- `H` — последовательность восьмеричных цифр.

Левая рекурсия в правилах `S`, `E`, `T`, `F`, `D` и `H` сохраняется. Она позволяет использовать восходящий синтаксический анализ и задаёт левую ассоциативность соответствующих операций.

Приоритет операций определяется структурой грамматики: сначала обрабатывается унарное отрицание, затем побитовое И, после него исключающее ИЛИ и побитовое ИЛИ.

### 5.2. Множества FIRST и FOLLOW

| Нетерминал | FIRST | FOLLOW |
|---|---|---|
| `S` | `a b c d e f g h i j` | `$ ;` |
| `A` | `a b c d e f g h i j` | `$ ;` |
| `V` | `a b c d e f g h i j` | `= & ^ \| ) $ ;` |
| `E` | `~ ( a–j 0` | `) $ ; \|` |
| `T` | `~ ( a–j 0` | `) $ ; ^ \|` |
| `F` | `~ ( a–j 0` | `) $ ; & ^ \|` |
| `G` | `~ ( a–j 0` | `) $ ; & ^ \|` |
| `B` | `0` | `) $ ; & ^ \|` |
| `D` | `0 1` | `0 1 ) $ ; & ^ \|` |
| `O` | `0` | `) $ ; & ^ \|` |
| `H` | `0 1 2 3 4 5 6 7` | `0–7 ) $ ; & ^ \|` |

Здесь `a–j` обозначает отдельные терминалы `a`, `b`, `c`, `d`, `e`, `f`, `g`, `h`, `i`, `j`; `0–7` — отдельные цифры от `0` до `7`.

### 5.3. Построение SLR(1)-таблицы

Для построения SLR(1)-таблицы грамматика дополняется правилом:

```text
S' -> S
```

Далее строится канонический набор LR(0)-ситуаций. Начальное множество формируется с помощью операции `CLOSURE`, а остальные состояния — с помощью операции `GOTO`.

Для незавершённых ситуаций в таблицу `ACTION` записываются действия переноса. Для завершённых ситуаций записываются действия свёртки по соответствующим продукциям на символах из множеств FOLLOW.

Таблица `GOTO` содержит переходы по нетерминалам.

В результате построения LR(0)-автомата получено **60 состояний**.

### 5.4. Обоснование принадлежности грамматики к классу SLR(1)

При построении таблицы синтаксического анализа проверяются возможные конфликты:

- конфликт переноса/свёртки;
- конфликт свёртки/свёртки.

Действия свёртки добавляются только на терминалах, входящих в FOLLOW соответствующего нетерминала.

При проверке построенной таблицы конфликтов переноса/свёртки и свёртки/свёртки не обнаружено.

Следовательно, построенная грамматика относится к классу **SLR(1)**.
