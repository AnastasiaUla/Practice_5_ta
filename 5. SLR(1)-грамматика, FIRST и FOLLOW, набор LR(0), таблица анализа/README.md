# Полученная SLR(1)-грамматика

**Файл модели:** [`grammar_slr1.jff`](grammar_slr1.jff). Язык: последовательности операторов присваивания, разделитель `;`, слева от `=` только переменная `a`–`j`.

![Грамматика в JFLAP](images/slr1_grammar.png)

## Продукции

```text
S -> S;A | A
A -> V=E
V -> a | b | c | d | e | f | g | h | i | j
E -> E+T | E^T | T
T -> T&U | U
U -> ~U | F
F -> V | (E) | %B | @O
B -> BG | G
G -> 0 | 1
O -> OD | D
D -> 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7
```

`S` — последовательность, `A` — присваивание, `E`/`T`/`U`/`F` — аддитивный, мультипликативный, унарный уровни и операнд, `B` — цепочка двоичных цифр (после `%`), `O` — цепочка восьмеричных цифр (после `@`). Левая рекурсия задаёт левую ассоциативность. Раздельные `G` и `D` исключают конфликт свёртки: после `%` может прийти только `G`, после `@` только `D`.

## Множества FIRST и FOLLOW

| Нетерминал | FIRST | FOLLOW |
|---|---|---|
| `S` | `a`–`j` | `$ ;` |
| `A` | `a`–`j` | `$ ;` |
| `V` | `a`–`j` | `$ & ) + ; = ^` |
| `E` | `% ( @ ~ a`–`j` | `$ ) + ; ^` |
| `T` | `% ( @ ~ a`–`j` | `$ & ) + ; ^` |
| `U` | `% ( @ ~ a`–`j` | `$ & ) + ; ^` |
| `F` | `% ( @ a`–`j` | `$ & ) + ; ^` |
| `B` | `0 1` | `$ & ) + 0 1 ; ^` |
| `G` | `0 1` | `$ & ) + 0 1 ; ^` |
| `O` | `0`–`7` | `$ & ) + 0`–`7` `; ^` |
| `D` | `0`–`7` | `$ & ) + 0`–`7` `; ^` |

## Канонический набор LR(0)-ситуаций

Грамматика дополнена правилом `S' → S`. Получено **51 состояние**. Для краткости `V → •a | •b | … | •j` означает десять ситуаций `V → •a`, …, `V → •j`; аналогично для `G` и `D`.

## Обоснование SLR(1)

В каждом состоянии для ситуаций `A → α•aβ` записан перенос, для завершённых `A → α•` — свёртка только на символах `FOLLOW(A)`. Проверка всех клеток: конфликтов «перенос/свёртка» — 0, «свёртка/свёртка» — 0 (JFLAP также построил таблицу без конфликтов). Грамматика принадлежит классу SLR(1).
