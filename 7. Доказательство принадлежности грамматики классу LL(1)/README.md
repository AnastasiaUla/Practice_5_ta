# Формальное доказательство принадлежности грамматики классу LL(1)

## Лексика

Лексер берёт максимальную буквенно-цифровую цепочку и проверяет её целиком: `NUM` — `0b[01]+` (двоичная), `0t[0-2]+` (троичная) или `[0-9]+` (десятичная); `ID` — 1–2 латинские буквы. Прочие цепочки отвергаются. Знаки `~ & + ^ = ( ) ;` — отдельные токены, конец ввода — `$`. Пробелы пропускаются.

## Грамматика анализатора

```text
P -> E R
R -> ; E R | ε
E -> ID N | ~ U Y X | ( E ) Y X | NUM Y X
N -> = E | Y X
X -> + T X | ^ T X | ε
T -> U Y
Y -> & U Y | ε
U -> ~ U | F
F -> ID | NUM | ( E )
```

`P` — непустая последовательность выражений, `N` выбирает между присваиванием и продолжением выражения. Слева от `=` допустима только переменная (`a+b=c` отвергается), присваивание правоассоциативно (`a=b=c` допустимо).

## FIRST и FOLLOW

| A | FIRST(A) | FOLLOW(A) |
|---|---|---|
| `P` | `ID NUM ~ (` | `$` |
| `R` | `; ε` | `$` |
| `E` | `ID NUM ~ (` | `$ ; )` |
| `N` | `= & + ^ ε` | `$ ; )` |
| `X` | `+ ^ ε` | `$ ; )` |
| `T` | `ID NUM ~ (` | `$ ; ) + ^` |
| `Y` | `& ε` | `$ ; ) + ^` |
| `U` | `ID NUM ~ (` | `$ ; ) + ^ &` |
| `F` | `ID NUM (` | `$ ; ) + ^ &` |

## Множества выбора продукций (SELECT)

| Продукция | SELECT |
|---|---|
| `P → ER` | `ID NUM ~ (` |
| `R → ;ER` / `R → ε` | `;` / `$` |
| `E → ID N` / `~UYX` / `(E)YX` / `NUM YX` | `ID` / `~` / `(` / `NUM` |
| `N → =E` / `N → YX` | `=` / `& + ^ $ ; )` |
| `X → +TX` / `^TX` / `ε` | `+` / `^` / `$ ; )` |
| `T → UY` | `ID NUM ~ (` |
| `Y → &UY` / `Y → ε` | `&` / `$ ; ) + ^` |
| `U → ~U` / `U → F` | `~` / `ID NUM (` |
| `F → ID` / `NUM` / `(E)` | `ID` / `NUM` / `(` |

## Доказательство

Грамматика LL(1), если для каждого нетерминала множества SELECT его альтернатив попарно не пересекаются.

- `R`: `{;}` и `{$}`. `E`: четыре альтернативы начинаются с разных токенов `ID`, `~`, `(`, `NUM`.
- `N`: `{=}` и `{& + ^ $ ; )}` не пересекаются. Для пустой ветви `FOLLOW(N)={$ ; )}` не содержит `=`.
- `X`: `{+}`, `{^}`, `{$ ; )}`; `Y`: `{&}`, `{$ ; ) + ^}` — не пересекаются.
- `U`: `{~}` и `{ID NUM (}`; `F`: `{ID}`, `{NUM}`, `{(}` — не пересекаются.

Во всех случаях продукцию однозначно выбирает один токен предпросмотра, возвратов нет. Следовательно, грамматика принадлежит классу **LL(1)**. Каждому нетерминалу соответствует функция программы: `program`, `rest`, `expression`, `after_id`, `add_tail`, `term`, `mult_tail`, `unary`, `factor`. Хвостовые продолжения `R`, `X`, `Y` реализованы циклами `while` (стандартная замена хвостовой рекурсии, язык тот же).
