## 2. Цель работы с постановкой  задачи

**Цель:** изучить методы синтаксического анализа контекстно-свободных языков, построить LL(1)- и SLR(1)-грамматики, определить множества FIRST и FOLLOW, а также реализовать синтаксический анализатор методом рекурсивного спуска.

**Вариант 3:**

1. **Часть 1:** построить LL(1)-грамматику для языка операторов присваивания. В выражениях используются двоичные целые константы, однобуквенные переменные `a`–`j`, унарная операция, а также бинарные операции с заданными уровнями приоритета.
2. **Часть 2:** реализовать анализатор методом рекурсивного спуска для языка выражений. Используются двоичные, троичные и десятичные целые константы, идентификаторы длиной от одного до двух символов, унарная и бинарные операции, присваивание.
3. **Часть 3:** построить SLR(1)-грамматику для языка выражений и последовательностей операторов присваивания. Используются двоичные и восьмеричные целые константы, однобуквенные переменные `a`–`j`, унарная и бинарные операции.

Для записи операций в работе используется следующая система обозначений:

| Операция | Обозначение |
|---|---|
| Унарное отрицание (побитовое НЕ) | `~` |
| Побитовое И | `&` |
| Побитовое исключающее ИЛИ | `^` |
| Побитовое ИЛИ | `|` |
| Присваивание | `=` |

Для обозначения систем счисления используются префиксы:

- `0b` — двоичная запись;
- `0t` — троичная запись;
- `0o` — восьмеричная запись;
- число без префикса — десятичная запись.

В качестве разделителя операторов в третьей части используется `;`. Скобки `()` применяются для группировки выражений.
